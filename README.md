# Guns & Orbital Strike (Fabric, Minecraft 26.3)

Four hitscan guns (pistol, assault rifle burst, shotgun, sniper), ammo, and two orbital strike devices.

- **Bullet**: ammo. Each trigger pull uses one. Creative mode needs none.
- **Orbital Strike Designator**: aim at the ground and right-click. A warning ring appears, then a beam hits.
- **Orbital Cannon**: bigger, slower, much more destructive.

Orbital strikes **destroy blocks**. Use them away from builds you care about.

Needs Fabric Loader 0.19.5+ and Fabric API for 26.3, and Java 25.
